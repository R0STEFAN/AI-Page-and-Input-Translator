## 🚀 Основні можливості

### 1. 🧠 Мульти-рушійна архітектура (Хмарні LLM + Локальний WebGPU)
Підтримка 5 провайдерів перекладу з можливістю гарячого перемикання:
* **⚡ Coarena Model API** *(Рекомендовано)*: Надшвидкий переклад (**~0.7 – 1.0 с**) через моделі `claude-haiku-5-5`, `minimax-m3-1-flash` та `claude-sonnet-5-5`.
* **🔓 OpenCode Inference API**: Підтримка каталогу з 41+ моделей (`nemotron-3.5-lightning`, `minimax-m3.1-flash`, `deepseek-v4.1-flash` тощо) з динамічним завантаженням доступних моделей.
* **🚀 OpenRouter API**: Підтримка роутера `openrouter/free` та безкоштовних моделей (`:free`) із захистом від блокування токенів міркування.
* **🌐 Google Gemini API**: Офіційний Google AI Studio API (`gemini-2.5-flash`, `gemini-3.5-flash`) із вимкненим thinking-бюджетом для прискорення відповіді до 0.9 с.
* **💻 Вбудована локальна нейромережа (WebGPU / Offscreen)**: 100% приватний офлайн-переклад без відправки даних на сервери за допомогою [Transformers.js v3](https://huggingface.co/docs/transformers.js) та моделі `Xenova/opus-mt-en-uk`.

### 2. 🎯 Інтерактивний інспектор секцій (Вибірковий переклад)
* Натисніть **«🎯 Перекласти блок/секцію»** або гарячу клавішу — і наводьте курсор на будь-який пост, гілку коментарів, твіт чи блок статті.
* Плавне підсвічування обраного контейнера синім неоновим контуром.
* Клік мишею — і перекладається **виключно цей блок**, зберігаючи контекст і структуру сторінки.
* Над перекладеною секцією з'являється плаваюча кнопка **`↺ Оригінал`** для миттєвого відкату без оновлення сторінки.

### 3. 📰 Розумний детектор головного контенту (Повна сторінка)
* Автоматично знаходить основний зміст статті або стрічки постів (Reddit, Twitter/X, HackerNews, Telegram Web, медіа).
* Не чіпає навігаційні меню, сайдбари, рекламу, лічильники та футер.
* **In-place заміна тексту**: дбайливо зберігає всі клікабельні посилання `<a>`, жирний шрифт, розмітку, блоки коду та емодзі.
* Можливість у будь-який момент повернути оригінальний текст одним кліком.

### 4. ✨ Переклад виділеного тексту
* Виділіть будь-яку фразу, речення чи абзац на сторінці.
* Натисніть гарячі клавіші **`Ctrl+Shift+X`** (або через контекстне меню правої кнопки миші -> *«✨ Перекласти виділене (AI)»*).
* Анімований пульсуючий індикатор під час генерації та вбудована кнопка скасування `↺`.

### 5. ✍️ Помічник написання (Переклад полів вводу)
* Пишіть чернетки коментарів, твітів, листів або повідомлень у будь-яких полях (`<textarea>`, `<input>`, `contenteditable`, чати, issue tracker).
* Натисніть **`Alt+T`** (або `Ctrl+Shift+U`) — AI перекладе ваш текст цільовою мовою (наприклад, англійською).
* **Природне мовлення**: на відміну від звичайних словників, AI перекладає ідіоматично, адаптує тон (ввічливий, технічний, дружній) і зберігає теги `@mentions`, змінні коду, посилання та форматування.

### 6. 🌙 Сучасний інтерфейс і Dark Mode
* Адаптивний дизайн спливаючого вікна та налаштувань (автоматична темна тема відповідно до системної теми OS).
* Відображення статусу активної моделі (`⚡ claude-haiku`, `🔓 nemotron`, `🚀 openrouter`, `🌐 gemini`, `💻 offline`).
* Індикатор прогресу пакетного перекладу у реальному часі.

## ⌨️ Гарячі клавіші (Shortcuts)

| Комбінація клавіш | Дія |
| :--- | :--- |
| **`Alt + T`** | ✍️ Перекласти текст у поточному полі введення |
| **`Ctrl + Shift + U`** | ✍️ Альтернативна комбінація для перекладу полів вводу |
| **`Ctrl + Shift + X`** | ✨ Перекласти виділений текст на сторінці |
| **`Alt + Shift + S`** | 🎯 Запустити інспектор секцій (клік для перекладу блоку) |
| **`Alt + Shift + P`** | 📄 Перекласти всю сторінку / повернути оригінал |
| **`Escape`** | ❌ Скасувати режим інспектора секцій |

*(Комбінації клавіш можна змінити в будь-який момент у `chrome://extensions/shortcuts`)*

## 📥 Встановлення в браузер (Chrome / Brave / Edge)

1. **Клонуйте репозиторій** або завантажте ZIP-архів:
   ```bash
   git clone https://github.com/R0STEFAN/AI-Page-and-Input-Translator.git
   ```
2. Відкрийте браузер і перейдіть на сторінку розширень:
   - Chrome / Brave: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. Увімкніть перемикач **«Режим розробника»** (*Developer mode*) у правому верхньому кутку.
4. Натисніть кнопку **«Завантажити розпаковане»** (*Load unpacked*) у лівому верхньому кутку.
5. Виберіть папку проєкту `AI-Page-and-Input-Translator`.
6. Розширення готове до роботи! Закріпіть іконку на панелі браузера.

## 🛠️ Архітектура проєкту

```
AI-Page-and-Input-Translator/
├── manifest.json              # Chrome Manifest V3 конфігурація
├── background/                # Фоновий Service Worker
│   ├── background.js          # Головний роутер повідомлень та контекстного меню
│   ├── storage.js             # Управління chrome.storage.sync
│   ├── coarena.js             # Інтеграція Coarena Model API
│   ├── opencode.js            # Інтеграція OpenCode Inference API
│   ├── gemini.js              # Інтеграція Google Gemini API
│   ├── openrouter.js          # Інтеграція OpenRouter API
│   └── offscreen-manager.js   # Життєвий цикл offscreen документа
├── content/                   # Клієнтські скрипти сторінки
│   ├── content.bundle.js      # Зібраний автономний бандл (CSP-сумісний)
│   ├── content.css            # Стилі інспектора, бейджів, анімацій та пульсації
│   ├── main-content-detector.js # Алгоритм виявлення суті сторінки та щільності
│   ├── section-inspector.js   # Візуальний інспектор блоків та плаваючий бейдж
│   ├── selection-translator.js# Логіка заміни виділення
│   └── input-translator.js    # Помічник вводу з підтримкою Shadow DOM
├── offscreen/                 # Офлайн нейромережа (WebGPU)
│   ├── offscreen.html
│   └── offscreen.js           # Transformers.js v3 пайплайн перекладу
├── popup/                     # Спливаюче вікно керування
├── options/                   # Повнофункціональна панель налаштувань
├── scripts/                   # Утиліти збірки та завантаження WASM/моделей
└── tests/                     # 147 автоматизованих модульних тестів (Node.js)
```
